# 视频极客压缩 (NP Video Compressor)

一个专为 Android 打造的高效相册视频极限压缩与原视频替换工具。

- **应用包名**：`cn.northpark.videocompressor`
- **默认安装包输出**：`np-video-compressor-1.0.2.apk`
- **作者团队**：NorthPark (cn.northpark)
- **官方主页**：https://northpark.cn

---

## 📱 核心功能特性

1. **读取全部相册视频**
   - 适配 Android 13+ (API 33+) 的 `READ_MEDIA_VIDEO` 权限与 Android 12 及以下 `READ_EXTERNAL_STORAGE` 权限。
   - 快速异步扫描系统 MediaStore 媒体库中的全部视频，读取首帧缩略图、文件名、精确文件大小、视频时长、分辨率等。

2. **多维排序（默认按大小排序）**
   - **文件大小 (从大到小)**：直观展现手机中占用空间最大的视频文件，便于迅速释放存储空间。
   - **文件大小 (从小到大)**
   - **视频时长 (从长到短)**
   - **修改时间 (从新到旧)**

3. **批量多选与操作汇总**
   - 支持点击卡片或点击右侧复选框精确多选，右上角支持一键**全选 / 取消全选**。
   - 底部常驻操作面板实时汇总已选中的视频数量与总大小，预估释放空间比例。

4. **100% 保持原始分辨率的极限压缩**
   - **绝不裁切画面尺寸**：源视频是 4K (3840x2160)、1080p (1920x1080) 还是 720p，压缩后一律保留原始宽高和画幅。
   - **高效视频编码**：优先使用 **H.265 / HEVC** 硬件编码器（若设备不支持则优雅降级为 H.264 / AVC），在相同画质下相比传统 H.264 节省约 40%~50% 额外码率。
   - **智能动态码率下压**：针对不同分辨率与原始码率，通过科学算法计算视觉几乎无损的极限低码率目标（例如 1080p 下压至 ~1.8 Mbps，4K 下压至 ~6 Mbps），音频转码为 AAC 96kbps，总体积通常可削减 **60% ~ 80%**。

5. **无缝替换源视频（兼容 Android 10/11/12/13/14+ 分区存储）**
   - **压缩后的视频日期和相册时间轴已与原视频保持严格一致**
   - **Android 11+ (API 30+)**：通过调用系统标准的 `MediaStore.createWriteRequest` 弹出原生安全修改授权弹窗，用户确认后通过 ContentResolver 的 `"wt"` 模式流覆盖写入原始 Uri，确保相册索引、原文件位置和系统缩略图完全保留并更新实际大小。
   - **体积安全防护**：转码后严格比对新旧文件大小，若压缩后体积反而没有变小，会自动保留原文件，杜绝反向变大。
   - **压缩战果汇报**：处理完成后弹窗展示释放的存储空间（如"已释放 2.45 GB"）及体积缩减百分比。

7. **内置“关于”对话框**
   - 菜单栏直达“关于”弹窗，提供作者信息（NorthPark）、版本号与软件核心设计理念说明。

## 🛠 命令行一键打包

在项目根目录下双击 **`build_apk.bat`** 即可在当前电脑命令行一键编译生成：
`app\build\outputs\apk\debug\np-video-compressor-1.0.0.apk`
